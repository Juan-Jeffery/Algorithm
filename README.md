# Algorithm Visualization System

A web-based interactive system for learning and visualizing classic algorithms.  
You can explore step-by-step animations and gain an intuitive understanding of how different algorithms work.  

👉 [Live Demo](https://juan-jeffery.github.io/Algorithm/main.html)

---

## Features Implemented

### 1. Sorting Algorithms
- Bubble Sort  
- Insertion Sort  
- Merge Sort  
- Quick Sort  

### 2. Graph Algorithms
- Depth-First Search (DFS)  
- Breadth-First Search (BFS)  
- Dijkstra's Algorithm (Shortest Path in Graph)  

### 3. Greedy Algorithms
- Huffman Coding  
- Activity Selection Problem  

### 4. Dynamic Programming
- Longest Common Subsequence (LCS)  
- Knapsack Problem  
- Floyd-Warshall Algorithm (Shortest Paths with Positive/Negative Weights)  

### 5. Backtracking
- N-Queens Problem  
- Sudoku Solver  
- Subset Sum Problem

## 📌 Tech Stack
- **Frontend:** HTML, CSS, JavaScript (D3.js for visualization)  
- **Design Goal:** Intuitive, educational, and interactive step-by-step demonstrations  

---

## 🎯 Purpose
This project is designed as a **learning tool** to help students and enthusiasts:  
- Understand algorithms visually  
- Observe step-by-step execution  
- Compare performance and strategy differences
